Automatic PD-gain design (PolyMorph, arXiv:2610.19615, Sec. "PD-gain design")

  lambda = sum_{i=1..3} M_ii(q0)            (base translational block -> lambda = 3 * total mass)
  Kp     = alpha^2 * lambda                 alpha = 0.8, same Kp for all joints
  Kd_i   = 2 * zeta * sqrt(M_ii(q0) * Kp)   zeta = 0.8, M_ii = joint diagonal of the mass matrix
  Kd     = median_i(Kd_i)                   same Kd for all joints

Computed with MuJoCo (robot_model/<robot>/<robot>.xml, floating base),
nominal posture q0: hip 0.0, thigh 0.9, calf -1.8.
M_ii includes the armature (MuJoCo adds dof_armature to the mass matrix diagonal).

Kd column "IsaacLab armature" uses the armature list in assets/<robot>_asset.py (the one used in training).
